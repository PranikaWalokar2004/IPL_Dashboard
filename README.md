# IPL_Dashboard
🏏 IPL Analytics Dashboard (2008–2022)
A comprehensive Power BI dashboard that provides deep insights into IPL team performances, player statistics, match outcomes, and season-level trends.
This project integrates multi-source data, advanced DAX measures, and interactive visuals to deliver meaningful cricket analytics.

📌 1. IPL Performance Summary
- Title Winners, Orange Cap, Purple Cap for all seasons
- Tournament 4s & 6s breakdown
- Toss decisions & their impact on match outcomes
- Venue-wise and season-wise team performance

📌 2. Batting & Bowling Analytics
* Batting Stats
- Total Runs
- Strike Rate
- 4s & 6s
- Consistency metrics
* Bowling Stats
- Wickets
- Economy
- Dot Balls
- Maiden Overs
- Dynamic filters to analyze any batsman or bowler

📌 3. Match Insights
- Winning percentage based on toss decisions
- Matches won by venue and result type
- Team-wise total wins across seasons
- Seasonal momentum & performance trends

📌 4. Project Workflow
- Requirement Gathering & Stakeholder Mapping
- Import Data from MS SQL Server & PostgreSQL
- Power Query Cleaning & Data Processing
- Data Modelling (3-table star schema)
- Time Intelligence Calculations (YTD, MTD, Seasonal)
- DAX Measures for KPIs
- Visualization, Insight Extraction & Reporting
